Laws

  1. FirstGenerate knowledge; never hand-write what the SDK or code can tell.
  2. SecondCheck, don't hope. Every rule has a deterministic gate.
  3. ThirdThe engine knows no Flutter rules. Packs do.
  4. FourthOne data format for CLI, MCP, desktop and web.
  5. FifthNever touch credentials. Irreversible steps need a human.
  6. SixthLocal first, no telemetry, Windows first-class.
