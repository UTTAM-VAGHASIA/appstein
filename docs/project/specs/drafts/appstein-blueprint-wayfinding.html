      Terminal regulations

      • 1Generate knowledge; never hand-write what the SDK or code can tell.
      • 2Check, don't hope. Every rule has a deterministic gate.
      • 3The engine knows no Flutter rules. Packs do.
      • 4One data format for CLI, MCP, desktop and web.
      • 5Never touch credentials. Irreversible steps need a human.
      • 6Local first, no telemetry, Windows first-class.

      Check before you fly

      • 1eCodex hooks and config paths. Fallback: verify through MCP, enforced in CI.
      • 1eOfficial plugin per project. Fallback: print the install commands.
      • 1ematerial_ui with dependencies. Switch only when all are compatible.
      • 1aFast checks under 5 s. Fallback: warm analysis in the MCP process.
      • M2Vendor policy changes. M1 launches no agents.
      • launchTrademark, domain, license, firm decision.
